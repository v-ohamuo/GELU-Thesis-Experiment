## Repository Structure

### 📂 Experiment 1: Depth Comparison
Comparing function approximation capabilities between shallow and deep networks.
- **func_f1_shallow.py**: Approximation using a single-layer network.
- **func_f1_deep.py**: Approximation using a 4-layer deep network to demonstrate depth efficiency.

### 📂 Experiment 2: Activation Properties
Analyzing theoretical failure modes of ReLU vs. GELU.
- **dying_relu.py**: Simulation demonstrating the "Dying ReLU" problem where neurons become inactive.
- **saturation_unbdd.py**: Analysis of saturation and unboundedness properties in activation functions.
